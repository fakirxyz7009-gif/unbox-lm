# Free Instrument Batch 005

**Built:** 2026-11-14

**Result:** 20 new playable packs adding **22,286,681 bytes** and **344 unique
recordings**. Every pack is `CC0-1.0`, and every one is a distinct instrument or
a distinct synthesized voice. This batch contains **no articulation alternates**.

Seventeen packs are recordings of physical instruments: a saxello, tenor
saxophone, folk harp, baroque bass recorder, three African lamellophones, hand
chimes, anvil, bell tree, brake drum, flexatone, gong, ocean drum, slit drum and
a toy train whistle, plus a jaw harp. Three are distinct synthesized keyboard
voices: a drawbar organ, a square lead and a sweep pad. All three are labelled
as synthesized in their device descriptions and provenance notes.

The catalog now contains 152 packs (148 redistributable, 4 private `Custom`),
with 144 `CC0-1.0`, three `CC-BY-3.0` and one `CC-BY-4.0` pack. No private
`Custom` packs or `D:\vsr` content was used.

No VSCO or Karoryfer slots were forced. VSCO's remaining SFZ programs are
alternate articulations or ensembles of instruments already represented, and
the unrepresented Karoryfer releases reviewed for this batch are commercial.
The distinct-instrument work therefore comes from VCSL and FreePats.

## Why this is 20 distinct voices

| Group | Count | Notes |
| --- | ---: | --- |
| VCSL recorded instruments | 16 | Seven melodic/wind/world instruments and nine percussion/whistle instruments |
| FreePats recorded instrument | 1 | Jaw harp, one fundamental with twelve performance variations |
| FreePats synthesized voices | 3 | Drawbar organ emulation, square lead and sweep pad |
| **Total distinct voices** | **20** | No alternate articulation packs |

The three African lamellophones are separate instruments, not alternate
articulations: a Tanzanian kalimba, a low-G Mavembe/Gandanga mbira and a low-F
Nyunga Nyunga mbira, each with its own tine layout and recordings. The two saxes
are also separate: a saxello (straight soprano) and a tenor saxophone.

  material, not samples from commercial songs.
- FreePats Jaw Harp is `CC0-1.0`. The source readme credits Eugene Vlaskin for

  playing jaw harp, N.K. Chayka for assistance, and Roberto for the FreePats
  bank. The pack keeps twelve of the source's 48 performance variations.
- FreePats Drawbar Organ is `CC0-1.0`. It is a synthesized emulation recorded
  from the free setBfree software, not a recording of a pipe organ. The pack
  uses the drawbar program only.
- FreePats Square Lead and Sweep Pad are `CC0-1.0`, synthesized by Roberto with
  ZynAddSubFX/Yoshimi. They are distinct playable synth voices, not acoustic
  instrument recordings.
- Visible device names and descriptions avoid manufacturer and model
  trademarks. Source names appear only in provenance fields.
- All source archives and repositories are pinned in the table and in
  `scripts/instruments/fetch-vcsl-batch-005.mjs` /
  `scripts/instruments/fetch-freepats-batch-005.mjs`.

## Build and verification

The VCSL downloader fetches the exact 286 WAVs and the recipes map them into
packs. The FreePats downloader verifies both archive SHA-256 values before
extracting them.

```bash
npm run fetch:instrument:vcsl-batch-005
npm run fetch:instrument:freepats-batch-005
npm run instrument -- recipe scripts/instruments/recipes/vcsl-saxello.json
npm run instrument -- recipe scripts/instruments/recipes/vcsl-tenor-saxophone.json
npm run instrument -- recipe scripts/instruments/recipes/vcsl-folk-harp.json
```

The four FreePats packs are imported from the pinned local/GitHub SFZ sources
described in the table; their exact build metadata is in `instrument.json` and
in the fetch scripts. The VCSL recipes only use the non-vibrato, sustain, normal
pluck or selected percussion recordings named above, not every articulation in
the source.

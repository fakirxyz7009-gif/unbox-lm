# Free Instrument Batch 003

**Built:** 2026-11-14

**Result:** 20 new playable packs adding **26,393,638 bytes** and **639 unique
recordings** to the catalog. Every pack is `CC0-1.0`.

The catalog now contains 112 packs (108 redistributable, 4 private `Custom`),
with 104 `CC0-1.0`, three `CC-BY-3.0` and one `CC-BY-4.0` pack. Every new pack
records its pinned source revision, author/credit, licence and provenance in
`public/instruments/<id>/instrument.json`, `public/instruments/CREDITS.md` and
`shared/instruments/catalog.ts`. No private `Custom` packs or `D:\vsr` content
was used.

Sixteen of the 20 are new distinct instruments. The four VSCO string/oboe
entries are alternate articulation/timbre programs for instruments already
represented in the catalog; they add playable devices but are not counted as
four new distinct instruments. The VSCO GM-style kit is a new distinct
percussion kit.

## Licence and credit notes

- All 20 repositories and releases used here are `CC0-1.0`. No `Custom`, NC,
  SA or unverified recordings were used.
- VCSL and VSCO 2 Community Edition are CC0-1.0 libraries by Versilian Studios.
  Their individual performers are not identified in the VCSL repository.
- FreePats Timpani and Tubular Bells are assembled from CC0 VCSL recordings by
  Roberto. FreePats Synth Percussion, FM Piano and Lately Bass are synthesized
  and edited FreePats releases; the repository READMEs and releases are CC0-1.0.
- Karoryfer Scarypiano processes public-domain piano recordings from the
  University of Iowa Musical Instrument Samples. Karoryfer String Cyborgs uses
  bowed-string recordings whose source performers are not individually
  identified. Squidpipes, Caveman Cosmonaut and Unruly Drums are Karoryfer
  Samples releases credited to Karoryfer Lecolds.
- Visible device names and descriptions avoid manufacturer/model trademarks.
  Source folder and program names are retained only as provenance.
- The VSCO GM-style kit keeps 20 core percussion lanes. The four VSCO
  articulation packs are documented as alternates, not distinct instruments.
  The Karoryfer and FreePats packs use key/velocity thinning where needed; the
  exact lane maps and pack limits are stored in each manifest.

## Build and verification

The five VCSL packs use baked recipes and the official WAV downloads:

```bash
npm run fetch:instrument:vcsl-batch-003
npm run instrument -- recipe scripts/instruments/recipes/vcsl-harmonica.json
npm run instrument -- recipe scripts/instruments/recipes/vcsl-dan-tranh.json
npm run instrument -- recipe scripts/instruments/recipes/vcsl-harpsichord.json
npm run instrument -- recipe scripts/instruments/recipes/vcsl-psaltery.json
npm run instrument -- recipe scripts/instruments/recipes/vcsl-frame-drum.json
```

The VSCO, FreePats and Karoryfer packs are imported from the pinned SFZ
revisions with `npm run instrument -- sfz …`. The source URL, attribution,
provenance notes, key/velocity thinning and pack limits are recorded in each
manifest and in the table above. The SFZ reader now drops source regions whose
velocity range is outside 0–127 or inverted, and the velocity thinner enforces
the same bounds, so every emitted zone is reachable by the manifest parser and
playback engine.

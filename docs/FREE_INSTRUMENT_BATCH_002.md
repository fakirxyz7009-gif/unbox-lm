# Free Instrument Batch 002

**Built:** 2026-11-14

**Result:** 20 new playable packs adding **22,345,744 bytes** and **607 unique
recordings** to the catalog. Nineteen packs are `CC0-1.0`; FreePats MuldjordKit
is `CC-BY-4.0` and includes its required DrumGizmo.org credit.

The catalog now contains 92 packs (88 redistributable, 4 private `Custom`), with
84 `CC0-1.0`, three `CC-BY-3.0` and one `CC-BY-4.0` pack. Every new pack records
its pinned source revision, author/credit, licence and provenance in
`public/instruments/<id>/instrument.json`, `public/instruments/CREDITS.md` and
`shared/instruments/catalog.ts`. No private `Custom` packs or `D:\vsr` content
was used.

Fifteen of the 20 are new distinct instruments. The five VSCO entries are
alternate articulation/timbre programs for trumpet, flute, organ, viola and
timpani already represented in the catalog; they are additional playable
devices, not five new distinct instruments.

## Build and verification

The five VCSL packs use baked recipes and the official WAV downloads:

```bash
npm run fetch:instrument:vcsl-batch-002
npm run instrument -- recipe scripts/instruments/recipes/vcsl-bongos.json
npm run instrument -- recipe scripts/instruments/recipes/vcsl-conga.json
npm run instrument -- recipe scripts/instruments/recipes/vcsl-balafon.json
npm run instrument -- recipe scripts/instruments/recipes/vcsl-tambourine.json
npm run instrument -- recipe scripts/instruments/recipes/vcsl-vibraphone.json
```

The VSCO, FreePats and Karoryfer packs are imported from the pinned SFZ
revisions with `npm run instrument -- sfz …`. The source URL, attribution,
provenance notes, key/velocity thinning and pack limits are recorded in each
manifest and in the table above. The converter now drops silent SFZ regions
instead of writing zones with an empty sample path; this was needed by the
Karoryfer hat program's silent choke regions.

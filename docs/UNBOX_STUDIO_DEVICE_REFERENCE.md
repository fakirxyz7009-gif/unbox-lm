# Unbox Studio Device & Reason Rack Extension Reference

This reference is generated from the device browser, the `DeviceSpec` registry, the legacy built-in registry, and the recorded-pack catalog. It describes what this checkout can instantiate; it is not a claim of Reason Rack Extension compatibility.

## Compatibility and sound-source labels

- **App-owned DSP model**: generated by Unbox Studio code using Web Audio; these are synthesized/modelled sounds, not recordings of a musician.
- **Recorded pack**: recorded audio played from bundled samples. Attribution can name a library creator, mapper, curator, or uploader; it is not a performer credit unless the source identifies that role. Check the pack license before redistribution.
- **Hardware-model DSP**: an original model of a hardware category; it does not load the hardware maker’s code or samples.
- **Legacy Web Audio device**: app-owned implementation registered in the legacy device factory.
- **Proxy DSP**: discovered VST library devices use placeholder/proxy processing and are not native VST/VST3 execution.
- **Legacy SoundFontEngine models**: built-in tabla, bansuri, sitar, guitar, piano, dhol, and harmonium buffers are generated by app-owned physical-model DSP; they are not imported SF2 banks or musician recordings. Private `Custom` stems can override some models in a personal build and are omitted from share builds. Workstation LOAD parses SF2 preset/instrument zone maps, key and velocity ranges, linked stereo sample pairs, root tuning, loops, selected envelope generators, scale tuning, initial filter cutoff, and the default velocity-to-cutoff and concave velocity-to-attenuation responses, plus exclusive classes. Custom SF2 modulators, full generator behavior and articulation fidelity remain incomplete; import does not verify sample provenance or license.
- None of these app-owned devices is an actual Reason Rack Extension. The Reason Rack Extension format has its own SDK and Reason host requirements.
- **Reason Rack plugin vs. Rack Extension:** Reason Free is a separate VST3/AU/AAX plugin that contains selected Reason Rack devices and opens access to Rack Extensions inside that rack. That does not make individual Rack Extensions generic VST3/AU plugins or establish Unbox compatibility; Unbox does not currently host Rack Extensions.
- **AI and sound**: the audio graph renders app DSP and recordings; Gemini features choose rack plans, device parameters, or mix notes, not audio waveforms. The unused `/api/generate-sound` endpoint was removed because it exposed hard-coded local song-derived patch files and had no client callsite. `Custom` recordings remain private to the local build and must not be shared without verified rights.

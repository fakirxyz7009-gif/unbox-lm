# Free Instrument Batch 006

**Built:** 2026-11-15

**Result:** 20 new playable packs adding **15,087,160 bytes** and
**208 unique recordings**. Every pack is `CC0-1.0`, and every one
is a distinct VCSL folder that was not represented by the 38 VCSL packs already
in the catalog. This batch contains **no articulation alternates and no repeated
Karoryfer, VSCO or FreePats slot**.

The batch is deliberately percussion-heavy because the remaining VCSL folders
are mostly rare or orchestral percussion. It also adds two baroque recorders, a
standard ocarina, a Renaissance organ and a hand-cranked siren for pitched and
sound-design range. The orchestral bass drum, cabasa, claps, cowbells, guiro,
hand bells, mark trees, ratchet, large shaker, slapstick, sleigh bells,
suspended cymbal, triangles, tubular glockenspiel and vibraslap are separate
VCSL folders, not alternate articulations of an earlier pack.

The catalog now contains 172 packs (168 redistributable, 4 private `Custom`),
with 164 `CC0-1.0`, three `CC-BY-3.0` and one `CC-BY-4.0` pack. No private
`Custom` packs or `D:\vsr` content was used.

The two recorders extend the existing bass-recorder family with different
instruments, not different articulations: soprano recorder and tenor recorder.
The ocarina is a separate VCSL instrument with its own sampled range. The
Renaissance organ uses the 8-foot rank of a small historical-style organ; the
existing pipe organ and drawbar organ are different instruments.

“Samples” counts the unique encoded `.ogg` files in each pack, not source
recordings, zones or velocity layers. The bass drum preserves its four recorded
dynamics as velocity layers with two round robins per layer. The tubular
glockenspiel preserves its three recorded dynamics as separate velocity layers.
Its source WAVs are labelled `A0`–`C1`, but pitch measurement puts the recorded
sounds six octaves above those labels (`A0_loud1.wav` measures MIDI 93.1, not
21). The recipe therefore applies +72 semitones and maps the actual G6–A7
range; the source labels remain visible in the manifest provenance.

## Build and verification

```bash
npm run fetch:instrument:vcsl-batch-006
# then run the 20 `npm run instrument -- recipe ...` commands listed in
# scripts/instruments/README.md
npm run test:browser-batch-006
```

- `npm run test:browser-batch-006` passed: **20/20 packs**, **208/208 unique
  recordings decoded**, and every pack played a mapped note or pad with audible
  output. Minimum measured RMS was **0.0015**; it is quiet but above the
  probe's audibility threshold.
- The focused policy test passed **30/30** and checks the pinned VCSL source,
  CC0 licence, generated credits, manifest zones, encoded sample sets, rack
  devices and catalog count.
- `npm test` passed **392 tests with 3 skipped and 0 failed**. The skips are the
  yt-dlp/ffmpeg check and two checks that need Ollama.
- `npm run lint` and `npm run build` passed.

This is browser Web Audio verification. No physical MIDI/audio-interface or G4
clean-machine validation is claimed.

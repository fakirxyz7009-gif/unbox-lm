# Free Instrument Batch 004

**Built:** 2026-11-14

**Result:** 20 new playable packs adding **13,709,728 bytes** and **419 unique
recordings** to the catalog. Every pack is `CC0-1.0`.

The catalog now contains 132 packs (128 redistributable, 4 private `Custom`),
with 124 `CC0-1.0`, three `CC-BY-3.0` and one `CC-BY-4.0` pack. Every new pack
records its pinned source revision, author/credit, licence and provenance in
`public/instruments/<id>/instrument.json`, `public/instruments/CREDITS.md` and
`shared/instruments/catalog.ts`. No private `Custom` packs or `D:\vsr` content
was used.

Thirteen of the 20 are new distinct playable voices. The five VSCO entries are
alternate staccato/spiccato articulations for instruments already represented
in the catalog, and the two FreePats electric-guitar entries are alternate
timbres of that instrument; these seven add playable devices but are not counted
as seven new distinct instruments.

## Licence and credit notes

- All 20 repositories and releases used here are `CC0-1.0`. No `Custom`, NC,
  SA or unverified recordings were used.
- VCSL and VSCO 2 Community Edition are CC0-1.0 libraries by Versilian Studios.
  Their individual performers are not identified in the VCSL repository.
- FreePats Jazz and Distorted Electric Guitar are real guitar recordings from
  the FSBS banks; the source readmes do not identify the individual guitarist.
  FreePats Synth Strings, Synth Brass and Synth Bass are synthesized banks made
  by Roberto for FreePats. They are documented as synthesized voices, not
  acoustic recordings.
- Karoryfer Bobobo is from Gogodze Phu Vol I (2018), a set of five Ghanaian
  bobobo drums. Gogodze Phu Vol II is the 2018 KVR Developer Challenge drum kit.
  Sneakybass credits Drogomir Smolken playing and mapping a 1958 double bass.
  Cowsynth uses samples of a replica medieval bagpipe as synthesizer
  oscillators. Swirly Drums is the full-kit program whose repository licence
  became free in version 1.104.
- Visible device names and descriptions avoid manufacturer/model trademarks.
  Source folder and program names are retained only as provenance.
- The five VSCO entries are alternate articulations, and the two FreePats
  guitar entries are alternate timbres; they are playable devices but are not
  counted as distinct instruments. The three FreePats synth banks and the
  Karoryfer Cowsynth pad are distinct synthesized voices.

## Build and verification

The five VCSL packs use baked recipes and the official WAV downloads:

```bash
npm run fetch:instrument:vcsl-batch-004
npm run instrument -- recipe scripts/instruments/recipes/vcsl-didgeridoo.json
npm run instrument -- recipe scripts/instruments/recipes/vcsl-strumstick.json
npm run instrument -- recipe scripts/instruments/recipes/vcsl-wine-glasses.json
npm run instrument -- recipe scripts/instruments/recipes/vcsl-mbira-dzavadzimu.json
npm run instrument -- recipe scripts/instruments/recipes/vcsl-clash-cymbals.json
```

The VSCO, FreePats and Karoryfer packs are imported from the pinned SFZ
revisions with `npm run instrument -- sfz …`. The source URL, attribution,
provenance notes, key/velocity thinning and pack limits are recorded in each
manifest and in the table above.
